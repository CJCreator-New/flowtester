Three design directions for Phase 1

Each prototype shows all four key screens: the URL entry, the plan map, the live view during testing, and the report. Open one, click through the screens, then come back and try the next. Pick the one that feels right — or parts of each.

Direction A
Cartographer — calm, paper-and-ink
Grows from the current wizard without breaking it. Pages appear as index cards joined by thin ruled lines on the same cool-paper background. Quiet during discovery, then findings pin to each card like sticky notes. The tone is a methodical inspector's report.

Direction B
Blueprint — dark, precise, architectural
Inverts to a deep navy canvas with white cards. Pages look like technical drawings; coloured paths trace each journey. The map feels like you're looking at the structure of the site. Findings appear as small red annotations — the architect's mark-up.
URL screen Plan map Live map Report
Direction C
Signal Board — light, colour-coded, status-forward
Keeps the light background but makes status the hero. Pages are bold, colour-coded by result from the start — grey → running (pulse) → green / amber / red. Closer to a modern dashboard. Best if the report is the most-used screen.

How to use these: each prototype is a single HTML file — no install, no server. The map nodes and findings are interactive: click a page card to open its side panel, click journey tabs to filter paths. Nothing is connected to the real runner yet.
